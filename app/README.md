# devpush

Deploy Docker Compose applications to your own servers with a git push. Run the dashboard on Cloudflare Workers or Node; the Linux agent builds and runs your applications.

<a href="https://devpu.sh/videos/devpush-demo.mp4">
  <img src="https://devpu.sh/videos/readme-demo.png" alt="Watch the devpush demo" width="1200" />
</a>

Includes environments, custom domains and HTTPS, encrypted variables, logs, server monitoring, backups, teams, a REST API and MCP.

## Get started

```sh
npx devpush@latest init
```

Choose Docker Compose or Cloudflare Workers. The wizard configures your dashboard and offers to deploy it. See [Installation](https://devpu.sh/docs/self-hosting/) for requirements.

You can also [use the hosted dashboard](https://app.devpu.sh).

For an existing project, install `devpush` and follow [Package integration](https://devpu.sh/docs/package-installation/).
